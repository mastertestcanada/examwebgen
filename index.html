    Specify Seat Labels Use this when you want seat numbers that aren't sequential e.g. (2, 4, 6), or seats with alphanumeric names like “A4, B6” or “Row H, Seat 5”. Without labels seats are numbered from 1 to the number of students. Labels are only used when Randomize seats is ticked; adding them ticks it.
    • Separate seats with commas: A1, A2, A3.
    • Or put each seat on its own line. Then a seat may contain commas, such as Row H, Seat 5.
    • You need at least one seat per student. Repeated labels count once; spare seats stay empty.

    Class List Options Change which field is the Student Number, export fields from the class list into the QR code (such as seat number).

    The number printed on each card and used by MasterTest Marker to match marks to students. Every student needs a different one.

    Fields exported into the answer card QR code Use this if you want this information to appear in the CSV export from your phone (e.g. SIS Login ID).

    The student name, ID and card serial are always included. Extra fields appear in MasterTest Marker's results; each one makes the QR code a little denser.
