# Changelog

Versions are written Major.Minor.Patch. The patch level goes up by one every
time an application is changed and built; the major and minor numbers change
only when requested.

## MasterTest Builder

| Version | Date       | Changes |
|---------|------------|---------|
| 0.4.12  | 2026-10-15 | MasterTest Builder's messages in French: errors, warnings, the run summary and the password prompts (`--messages-language en/fr`, by default the computer's language; MasterTest Web uses the page's language and redraws them when it changes). The messages are translated when shown, from the templates in `mtbuilder/messages.py`; `tools/check_messages.py` (part of the smoke test) lists any message without French. |
| 0.4.11  | 2026-10-15 | MasterTest Web in English and French: English \| Français at the top (first the browser's language, then remembered), with the print language following until chosen; the texts are in `web/i18n.js`. Messages from MasterTest Builder itself stay in English. CSV files: class lists and title maps are read with commas, semicolons or tabs (whichever the first line uses), and `answer_key.csv` is written with semicolons and decimal commas for `--print-language fr` (`--csv-separator comma/semicolon` to choose; in MasterTest Web under Advanced Options), with French column headings. |
| 0.4.10  | 2026-10-15 | Print language and decimal mark. `--print-language fr` prints the program's own text in French (instructions, headings and labels on exams, answer cards, merged sheets, answer key and attendance sheet; answer-card instructions from `answerCardInstructions.fr.html`); the quiz is printed as written. `--decimal-mark point/comma` (default: comma for French) for calculated-question values, points and the number-box instructions (`[[DECIMAL MARK]]` in an instructions file). The answer key records the decimal comma (key flags bit 0) for MasterTest Marker 0.4.1. Attendance sheets sort accented names beside their plain letter. MasterTest Web: Printed in English / Français beside Paper Size, and a Decimal mark choice in Print Options. |
| 0.4.9   | 2026-10-15 | Chinese, Japanese and Korean text: printed with a CJK font for one region's writing style, mixed freely with English and other text in the question font. `--cjk-region auto/sc/tc/jp/kr` (auto: Simplified Chinese for mostly Han text, else Japanese or Korean from kana and Hangul) and `--cjk-font`; by default a font installed for the region is used (Noto Sans CJK, Microsoft YaHei, Yu Gothic, Malgun Gothic, PingFang and others), and without one the characters print as '?' with a single warning. MasterTest Web: a region choice in the quiz's grey box when the quiz has such text, and the region's Noto Sans CJK (11 MB) downloaded from the site only when needed (`tools/make_cjk_fonts.py`, `build_web.py --cjk`). Fonts with PostScript outlines are converted once and kept in a cache folder. Fix: such fonts in a collection (.ttc) could not be used. README: right-to-left and shaped scripts are not supported. |
| 0.4.8   | 2026-10-15 | Option letters are Unicode enclosed characters: circled Ⓐ Ⓑ Ⓒ by default, `--option-letters filled` for 🅐 🅑 🅒, `plain` for A B C, in any option font (by default the question font). Fonts without these letters (most) get them from MasterTest Enclosed, a 52-letter subset of Noto Sans CJK supplied in `fonts/enclosed/`. Open Sans (many alphabets) and Source Code Pro (for code) are supplied with the program, with bold and italic faces. Fix: characters beyond U+FFFF (such as 🅐) are copied from the PDF and read aloud correctly. MasterTest Web: a Use Enclosed Characters checkbox under Option font, with circled and filled examples. |
| 0.4.7   | 2026-10-15 | The option marker (a period after the option letter) is now off by default: `--option-dot` prints it. `--font` and `--option-font` also take the fonts supplied with the program by name; `--list-fonts` lists the built-in, supplied and installed fonts. MasterTest Web: the Font and Option font lists offer the built-in and supplied fonts, the fonts installed on the computer (Chrome and Edge) and a font file of your own, sent to the program with the run; a configuration that names a font not available asks for it again. Wizard wording: Specify Seat Labels (with the class's student count), Class List Options, "Fields exported into the answer card QR code", Attendance Sheet Options and Layout; no placeholder in the seat-label box. |
| 0.4.6   | 2026-10-15 | MasterTest Generator is now MasterTest Builder: `python mastertest_builder.py` in the `builder` folder (Python package `mtbuilder`); MasterTest Web keeps its name and shares the version. Continues from MasterTest Generator 0.4.3. New QR codes, MasterTest QR format 1: answer cards, single-page quizzes and merged sheets are schema 0x10 (kind, answer width and sheet number each in a byte of their own, in place of the five flag bits added over earlier versions), answer keys 0x11 (one format for every question type) and password-protected keys 0x18; they are read by MasterTest Marker 0.4.0 and later only, and exams printed by MasterTest Generator can no longer be marked. Padding always means "as many bubbles as the quiz's question with the most options", and merged-sheet bubbles always end at the right edge of the answer area. Removed: the option names of MasterTest Generator 0.3.4 and earlier and their messages, `--use-item-banks` and `--pad-options`, old page-size spellings (`Tabloid-Duplex-Landscape`, `letter-singlePage`, ...) and old page-option spellings, and MasterTest Web's unlinked "All options" page. README rewritten without version history. |
