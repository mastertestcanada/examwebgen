# Changelog

Versions are written Major.Minor.Patch. The patch level goes up by one every
time an application is changed and built; the major and minor numbers change
only when requested.

## Exam Generator

| Version | Date       | Changes |
|---------|------------|---------|
| 0.1.0   | 2026-10-05 | First build. Reads Classic and New Quizzes Canvas exports (`--quiz`, `--list-quizzes`); multiple-choice, true/false and multiple-answers questions with up to six options; question selection with `--questionBank` (none, maxItems, UseItemBanks, titleMap); per-student or numbered variants; class lists, blank cards and seat randomization; Canvas HTML rendering (text styles, colours, fonts, sizes, alignment, lists, preformatted text, tables, images) with `[[variables]]`; font, margin, option-letter, column, points and page-size options; page options for collation, title page and padding; answer cards with schema 0x02 QR codes; attendance sheet; answer key and manifest; reproducible output with `--seed`. |
| 0.1.1   | 2026-10-05 | Questions and options are first put into a fixed pre-randomized order (seeded from the quiz identifier); card QR codes now index that order instead of the export order. New `answer_key.pdf`: one page with a schema 0x03 QR code holding points and correct options for every question. Exams longer than 100 questions spill onto further answer cards (card index in QR flag bits 5-7, up to 8 cards). New page option `collateTitlePages` (individual title pages in `title_pages.pdf`). New `--shuffleOptions true/false`. Console warning for empty options; at most 8 options per question in the export. |
| 0.1.2   | 2026-10-05 | Removed `--shuffleOptions`: options are always shuffled. New page option `padOptions`: answer cards print six bubbles (A-F) for every question instead of one per printed option. |
| 0.1.3   | 2026-10-05 | New page sizes `letter-singlePage` and `A4-singlePage`: questions and answer area on one page per student, with an error when they do not fit. In these sizes `collateExams`/`padExam` act as `collateAnswerCards`/`padAnswerCards`, and the title-page options are refused. Single-page cards carry QR schema 0x04. Answer cards and quiz pages are now written only after all of them have been built without error. |
| 0.1.4   | 2026-10-05 | New page option `noInstructions`: the quiz instructions are not printed, on any page size. |
| 0.1.5   | 2026-10-06 | Card QR layout changed: the fixed id and name fields are replaced by a count of length-prefixed data fields (name, number, then `--addToQR` columns; blank cards carry their serial). New `--addToQR`, `--preferId` and `--qrQuality` (L/M/Q/H, also applied to the answer key). `sis login id` is recognised as a student-number header; the left-most matching column is used unless `--preferId` is given. Student numbers may now be any text. |
| 0.1.6   | 2026-10-06 | Card QR data fields now carry their names: each field is a length-prefixed name followed by a length-prefixed value, in position order. Blank cards carry one field named `Serial`. |
| 0.1.7   | 2026-10-06 | Reverted 0.1.6: card QR data fields hold values only again. The field names are now stored once, in the answer key QR code (field count and length-prefixed names before the question count), in the order the values appear on the cards. |
| 0.1.8   | 2026-10-06 | Class-list rows with an empty student number are skipped with a warning instead of stopping the program, so a Canvas gradebook export can be used directly. |
| 0.1.9   | 2026-10-06 | For ExamMaster: the answer key QR code now carries the exam name (after the hash); card QR flags gain bit 1 (A4 paper) and bit 2 (six bubbles per question) so a scanner knows the card layout without guessing. |
| 0.1.10  | 2026-10-07 | New page sizes `Tabloid-Duplex-Landscape` and `A3-Duplex-Landscape`: exams are imposed two letter/A4 pages per side on landscape tabloid/A3 sheets in booklet order, with the title page first and a blank final page; the answer card is one folded four-page sheet (400-question limit); the answer key stays on letter/A4. |
| 0.1.11  | 2026-10-07 | New `--password`: the answer-key QR code is encrypted with AES-256-GCM under a key derived from the password and the quiz hash (schema 0x05). The exam name stays readable; a warning is shown for short passwords. |
| 0.1.12  | 2026-10-07 | `--password` now derives the AES key with PBKDF2-HMAC-SHA256 (600,000 iterations, salted with the key sheet's header) instead of a single SHA-256; flag bit 0 of the protected key marks this. Keys made with 0.1.11 `--password` must be regenerated. |
| 0.1.13  | 2026-10-07 | `--password` no longer takes the password on the command line: it prompts for it (typed twice, hidden), or reads one line from standard input when piped. |
| 0.1.14  | 2026-10-11 | Written answers. Formula (`calculated_question`) questions print with one of their exported value sets (chosen per variant, recorded in the card QR code) and are answered in a six-cell number box on the card; fill-in-the-blank questions (`short_answer_question`, and `fill_in_multiple_blanks_question` with one blank) are answered in an open box. The boxes take the place of the bubbles, so card layout and capacity are unchanged. Fill-in-multiple-blanks questions with two or more blanks are omitted with a warning. New answer-key schema 0x06 (per-question kind, answers and tolerance), used only when an exam has written questions; protected keys mark it with flag bit 1. The manifest lists each question's kind, value set and answers. |
| 0.1.15  | 2026-10-11 | New `--calculatedInstructions` and `--fillblanksInstructions`: replace the instruction line printed under every calculated question or fill-in-the-blank question (the latter also covers Classic short-answer questions); `None` or an empty string prints no line. |
| 0.2.0   | 2026-10-11 | Version numbering moves to 0.2.0 (minor version raised on request); no functional change from 0.1.15. |
| 0.2.1   | 2026-10-11 | New `--questionSpacing`: the space between questions (a length; a bare number is points). Default unchanged at 0.9 x the font size. |
| 0.2.2   | 2026-10-12 | New page sizes `letter-merged` and `A4-merged`: questions in two columns with each answer (bubbles A-D, a number box or a text box) beside its question, about 30 short questions per letter page at the new 9 pt default; longer quizzes continue on further sheets. Blank cards get handwritten student-number and seat boxes. Exports with a question of more than four options are refused for these sizes. New card QR schema 0x07 records each answer's position. Other page sizes are unchanged. |
| 0.2.3   | 2026-10-12 | Written-answer cells (number boxes, short-answer boxes, and the student-number and seat boxes of blank merged sheets) are now printed as light-grey shaded cells with white gaps instead of outlines: in phone photos taken without flash, thin grey outlines came out as dark as pencil, while a solid light grey stays clearly lighter than any writing. New `--cellShading <percent>` (default 15; `0` or `off` for outlined boxes as before). Merged sheets have larger answer cells, 15 x 19 pt instead of 13.2 x 16 pt. Card QR flag bit 3 marks shaded cells and bit 4 (merged sheets) the larger cells. New `tools/colour_test_sheet.py` prints the box-style test sheets. Multiple-choice bubbles are unchanged. |
| 0.2.4   | 2026-10-13 | New `--fillblanksBlank "<text>"`: what is printed in place of the blank in fill-in-the-blank questions (default `__________`; `None` or `""` prints nothing). New page option `oneColumn` for `letter-merged` / `A4-merged`: the questions in one full-width column with the answers at the right margin (two columns stay the default); the QR code describes the answers as before, so ExamMaster needs no update. The sample export used by the smoke test gains a fill-in-the-blank question. |
| 0.2.5   | 2026-10-13 | New `--answerWidth <len>`: the width of the written-answer boxes (answer column), on answer cards, single-page quizzes and merged sheets. Number cells, short-answer boxes, bubble pitch and size and row height scale with it; on cards the columns (at most four) and rows per column are as many as fit (e.g. letter: 100 per card by default, 63 at 1.6 in, 24 at 200 pt), on merged sheets the question text narrows or widens. A non-default width sets bit 7 of the card QR schema byte and adds a width byte after the hash (needs ExamMaster 0.2.16; older versions refuse such cards). The default layout and QR codes are unchanged. |
| 0.3.0   | 2026-10-13 | Version numbering moves to 0.3.0 (minor version raised on request). New `--answerCardInstructions <file>`: the instructions printed on answer cards, single-page answer areas and merged sheets now come from an HTML file, rendered with the same tags as question text (styles, colours, fonts, lists, tables and images, found next to the file); by default `answerCardInstructions.html` beside the program, which holds the previous text (a built-in copy is used if it is missing). Elements can carry `data-show="..."` (card, single, merged, compact, blank, named, written; `!` negates) to print only on some cards; the program stops with a message if the text does not fit. Single-page quizzes now report layout errors with their message. The sample export gains two multiple-answer questions. New `tools/test_pack.py` builds `tests/test_pack.pdf`: a fixed-seed exam with multiple-choice, multiple-answer, true/false, fill-in-the-blank and calculated questions on letter, letter-merged (two columns and one column), letter-singlePage and Tabloid-Duplex-Landscape, each with its own answer key, for testing layout and recognition; the release workflow builds it too and attaches it to releases. |
| 0.3.1   | 2026-10-13 | `--answerCardInstructions None` (or `""`) prints no answer-card instructions on cards, single-page quizzes or merged sheets, so they can be given in the quiz instructions instead; the bubble examples on cards stay. |
| 0.3.2   | 2026-10-13 | The "Correct / Incorrect" example bubbles on answer cards and single-page quizzes are no longer drawn separately: they are now part of `answerCardInstructions.html`, as images in the new `images` folder beside it, so they can be changed or removed with the rest of the instructions, and `--answerCardInstructions None` prints no examples either. The card looks the same by default. |
| 0.3.3   | 2026-10-13 | Wider answers on merged sheets. With `--pageOptions oneColumn`, `--answerWidth` now goes up to 255 pt (it was held to the two-column limit of 148 pt letter / 139 pt A4, which still applies to two columns). Bubbles and box height now stop growing at 120 pt, so wider boxes only get longer: a 200 pt box is 25 pt tall instead of 42 pt, and more questions fit on a sheet. Sheets wider than 120 pt carry the scale width in the QR code (bit 6 of the schema byte) and need ExamMaster 0.3.1 or later; older versions refuse them. Answer cards and single-page quizzes are unchanged. |
| 0.3.4   | 2026-10-13 | Seats and attendance sheet. `--randomizeSeats <file>` is now `--randomize-seats "<seats>"`: the seat labels are given as a comma-separated list instead of a CSV file (no value: seats 1..N, as before). `--attendenceSheet` is replaced: `attendance.pdf` is now made whenever there is a class list, with Student Name, Student Number and Signature, plus a Seat column with `--randomize-seats`. New `--add-attendance-field "<fields>"`: extra columns, filled from the class list when it has a column of that name, otherwise empty. New `--attendance-sort "<fields>"` (sort by any sheet or class-list column, numbers in order) and `--attendance-orientation portrait/landscape`. The old option names stop with a message explaining the new ones. `samples/seats_example.csv` is removed. |
| 0.3.5   | 2026-10-13 | Consistent command line. Every option name is now lower case with hyphens, and the old names stop with a message naming the new one: `--class-list`, `--student-id-column` (was `--preferId`), `--add-qr-field` (`--addToQR`), `--qr-quality`, `--blank-cards` (`--blanks`), `--page-size`, `--page-options`, `--question-spacing`, `--answer-width`, `--cell-shading`, `--answer-card-instructions`, `--option-font`, `--option-font-size`, `--option-columns`, `--option-dot` / `--no-option-dot` (was `--optionDot true/false`), `--calculated-instructions`, `--fill-blank-text` (`--fillblanksBlank`), `--fill-blank-instructions`. `--questionBank` is split into `--max-items <#>`, `--use-item-banks` and `--title-map <file>`. Page options are hyphenated (`collate-exams`, `title-page`, ...; old spellings still accepted) and the three that were not about pages are options of their own: `--pad-options`, `--no-quiz-instructions`, `--columns 1/2`. Page sizes are `letter`, `a4`, `letter-single-page`, `a4-single-page`, `letter-merged`, `a4-merged`, `tabloid-booklet`, `a3-booklet` (case and hyphens in values are ignored; the old names still work). `--randomize-seats` is now a switch (seats 1..N) and `--seat-labels "<seats>"` draws from a list, so the export path can no longer be taken for a seat list. A length without a unit is points everywhere; margins were inches, so a bare margin below 5 is refused with a hint. `none` or `""` turns off any text option. Lists accept double-quoted items. `--attendance-sort` accepts ` desc` after a column. `--help` is grouped by topic; a mistyped option gets a suggestion; `-o` is short for `--output`; `@<file>` reads options from a text file. `manifest.json` records the options under their new names. Output for the same settings is unchanged. |
| 0.3.6   | 2026-10-13 | Exam Generator in the browser. `tools/build_web.py` builds a folder of static files (about 21 MB) that runs the program entirely in the browser with Pyodide 0.29.5: a form built from the program's own options, file pickers for the export, class list, title map and instructions, a password field, saving and loading options as an `@options.txt` file, and a zip of the results to download. Files stay in the browser tab's memory and are cleared after each run; nothing is uploaded or stored. The output is identical to the desktop program's (`tests/web_test.mjs` checks it on every push), and the release workflow attaches `exam_generator_web_<version>.zip`. The answer-key password is now derived with cryptography's PBKDF2 where Python's hashlib lacks it (same key). |
