# Changelog

Versions are written Major.Minor.Patch. The patch level goes up by one every
time an application is changed and built; the major and minor numbers change
only when requested. MasterTest Web shares MasterTest Builder's version.

## MasterTest Builder

| Version | Date       | Changes |
|---------|------------|---------|
| 0.5.14  | 2026-10-21 | All translations in one place: mtbuilder/locales/<language>.json holds what the exams print, the program's messages and MasterTest Web's text (written into the page when it is built), with each language's rules (label colon, usual decimal mark, singular below two). A new language is a new file. tools/check_translations.py (in the smoke test) replaces check_messages.py and also checks the printed texts and the page's text. MasterTest Web: "answer_key.csv :" with the French colon. |
| 0.5.13  | 2026-10-21 | QR codes in a new, smaller format (format 2): the student number takes 5 bytes, answer positions on merged sheets are packed, and the answer key is compressed (a protected key for a 34-question exam: 596 → 401 bytes, so a smaller, easier-to-read QR code). Needs MasterTest Marker 0.5.9 or later; exams printed by earlier versions must be printed again. MasterTest Web: Open Sans and Source Code Pro are downloaded only when chosen as a font (the program's download is about half the size). Unused code removed. |
| 0.5.12  | 2026-10-21 | Faster, smaller PDFs. Question and option text is parsed once and reused for every student's exam (the same output); each kind of lettered bubble is drawn once per PDF and stamped where needed (answer cards and merged sheets about 15% smaller, the same appearance); on a desktop that can fork, exam booklets are made several at a time. 30 blank booklets: 4.7 s before, 2.2 s now on two cores. The optional `rl_accel` package (reportlab's C speed-ups, in requirements.txt) gives about 20% more, with identical output. |
| 0.5.11  | 2026-10-21 | MasterTest Web starts faster. The answer-key password no longer needs the cryptography library (about 2.3 MB with its helpers): AES-256-GCM is plain Python (`mtbuilder/aesgcm.py`, checked against cryptography in the smoke test) and the key is derived with PBKDF2 from Python's hashlib on the desktop, with the browser's own crypto in MasterTest Web. fontTools (1.1 MB) loads only when an uploaded OpenType font must be converted; fonts are described by reading their tables directly. A service worker keeps Python, the libraries, the app and the fonts in the browser, so later visits start without downloading them. `cryptography` is no longer in requirements.txt. |
| 0.5.10  | 2026-10-21 | The dotted leaders of matching items are drawn as one path each, not a circle per dot, so merged quizzes stay small (the browser test's output had grown from 144 KB to 371 KB). |

Only the printed name changes; the quiz hash stays, so the cards still match the answer key. MasterTest Web: the name above the quiz summary is editable, with "Use the quiz's name" to go back; it applies to that run and is not saved in configurations, which are used with other quizzes. |
| 0.5.6   | 2026-10-21 | Essay questions (Canvas Classic and New Quizzes), marked by hand in MasterTest Marker 0.5.7 and later. They come after every other question of an exam, still drawn from item banks and shuffled, but only among themselves. Each gets an answer space of 1/4, 1/2, 3/4 or a whole page, given in its name in Canvas (`Causes of the war (1/2 page)`; students do not see question names), otherwise `--essay-space` (default 1/4), and `--essay-space-all` gives every essay that size. A page is the card's writing area, the same on letter and A4. On answer cards the spaces follow the last card's answer rows, which then take only the rows they need, with the question's number and points and light writing lines; an essay that does not fit goes on a further card. On merged sheets each essay's question and space run across the whole width under the other questions, or on further sheets. Exam booklets say where to answer. Single-page quizzes leave essays out, with a warning. New answer-key record kind 4 (points and the space in quarters of a page). MasterTest Web: Essay space in Print Options, with For every essay; essays counted in the quiz summary. `tools/sample_essays.py`; the test pack has two sections with essays. |
| 0.5.5   | 2026-10-21 | Rules between questions (`--question-rules on/off`): a thin grey line between one question and the next, so each question is easy to follow across to its answer. On by default for one-column merged sheets, where the answers can be far from the questions; it runs from the question numbers to just before the answers, clear of what MasterTest Marker reads. Off by default elsewhere (two-column merged sheets, booklets and single-page quizzes, where it runs the full width). MasterTest Web: Rule Between Questions in Print Options, ticked for Merged One Column and following the layout until changed. The test pack is rebuilt. |
| 0.5.4   | 2026-10-20 | Merged quizzes: the Title page option (`--page-options title-page`) decides where the quiz instructions go, as for booklets. With it, a title page with the quiz title and instructions comes before the first sheet (made smaller to fit; not scanned), and `pad-title-page` adds a blank page after it. Without it, the instructions are printed above the questions on the first sheet however long they are; previously instructions longer than half a column always got a cover page. When they leave no room for question 1, the program says to shorten them, use a title page or leave them out. Fix: on two-column merged sheets, the right-hand column of the first sheet could start over the instructions; it now starts below them. MasterTest Web: Title page and Pad title page are available for the merged layouts. |

README rewritten without version history. |
